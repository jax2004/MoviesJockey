# 🎬 MovieJockey

MovieJockey is a responsive movie discovery web application built using Vanilla JavaScript and the OMDb API. The application allows users to search movies, explore trending titles, view detailed movie information, and get real-time search suggestions through dynamic API integration.

# 📌 Features

* 🔍 Real-time movie search
* 🎞️ Trending movies section
* ⚡ Dynamic autocomplete suggestions
* 📖 Detailed movie information display
* 🎚️ Horizontal movie slider with navigation
* 📱 Responsive design for desktop and mobile devices
* ⚠️ Basic error handling and input validation
* 🎨 Smooth UI interactions and hover effects
* ⌨️ Search using Enter key support
